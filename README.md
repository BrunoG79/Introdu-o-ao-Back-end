# Introdução ao Back-end

##  O que  é Back-end?
Back-end é o motor e o cérebro invisível de qualquer aplicativo ou site.

Enquanto você clica nos botões e vê o design na tela (o Front-end), o Back-end trabalha nos bastidores para:

Guardar dados: Salva suas fotos, senhas e histórico de compras.

Executar regras: Checa se a sua senha está certa ou calcula o valor do frete.

Proteger tudo: Garante que apenas você tenha acesso à sua conta.

Em uma frase: Se o Front-end é a lataria e o painel bonito de um carro, o Back-end é o motor que faz ele andar de verdade.
## O que é API?
A API é basicamente o mensageiro invisível da internet. Quando você clica em algo num aplicativo — tipo ver o mapa no Uber —, a API vai até outro sistema (como o Google Maps), pega a informação necessária e traz de volta para a sua tela em um piscar de olhos. Ela é a ponte que faz programas totalmente diferentes conversarem sem complicação.
## O que é Front-end
Front-end é a parte visual de um site ou aplicativo — ou seja, tudo o que você vê, clica e interage.

Os 3 pilares em uma frase cada:
HTML: É o esqueleto (cria os textos, imagens e botões).

CSS: É o estilo (define cores, fontes e onde cada coisa fica).

JavaScript: É o movimento (faz os botões funcionarem e as coisas mudarem na tela).
